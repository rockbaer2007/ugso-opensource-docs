# ioBroker Publishing Assistant

Interactive TypeScript CLI for npm, GitHub and the ioBroker adapter catalogue.

Use the menu to check package versions and provenance, configure a trusted publisher and start a release using an existing GitHub workflow. You can also request another check on an existing catalogue pull request.

Requires Node.js 24 or later, npm, Git and an authenticated GitHub CLI. Extract the ZIP and run `npm start -- menu` from the extracted folder.
