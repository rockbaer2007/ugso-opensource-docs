# Plugins vérifiés

Cette page répertorie les plugins ATLAS recommandés ou suivis comme nouvelles propositions externes. Les plugins vérifiés ont fait l'objet d'un contrôle minimal du manifeste, de l'URL de lancement, de l'icône, des fuites évidentes de secrets et des accès de chemins non sûrs.

::: warning Remarque
ATLAS est encore en développement. La vérification ne remplace pas votre propre évaluation avant une utilisation en production.
:::

## Signification des états

| État | Signification |
| --- | --- |
| vérifié | Le plugin a fait l'objet d'un contrôle de base et correspond à l'état actuel d'ATLAS. |
| expérimental | Le plugin est utilisable, mais son fonctionnement ou son contrat évolue encore visiblement. |
| non vérifié | Le plugin a été proposé ou découvert, mais n'a pas encore été examiné par ATLAS. |
| obsolète | Le plugin ne correspond plus à l'état actuel d'ATLAS. |
| rejeté | Le plugin n'est pas recommandé pour des raisons techniques, juridiques ou de sécurité. |
