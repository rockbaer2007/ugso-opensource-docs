# Erste Schritte

## Voraussetzungen

- Windows 10 oder Windows 11
- passende .NET Desktop Runtime
- Dashboarddatei oder unverschlüsselte Backupdaten

## Installation

1. Öffne die [HADash-Releases](https://github.com/rockbaer2007/HADash/releases).
2. Lade das aktuelle portable ZIP-Paket herunter.
3. Entpacke es in einen eigenen Ordner.
4. Starte `HADash.exe`.

## Unterstützte Formate

- `.dash`
- `.yaml`
- `.yml`
- `.json`
- `.txt`
- weitere Dateien über `Alle Dateien (*.*)`
