## Documentation Goals

Integration documentation should include:

- installation through HACS and manual installation where useful
- prerequisites and minimum Home Assistant version
- setup through UI or YAML
- required credentials, tokens or local services
- entities and important controls
- typical automations or dashboards
- troubleshooting
- version, original source, license and freshness status
