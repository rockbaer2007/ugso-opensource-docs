## flex-table-card {#reference-flex-table-card}

The `flex-table-card` is a HACS/Lovelace card for Home Assistant that allows you to display tabular data very flexibly. It is particularly suitable for lists with many rows or columns, for example package lists, sensor overviews, battery levels, device lists or static reference tables.

### What the card can do {#was-die-karte-kann}

- display any number of columns and rows
- Read data from entities, attributes, actions/scripts or static data
- output nested data using dot notation
- Format cells using `prefix`, `suffix`, `align`, `fmt` and `modify`
- Sort, limit and optionally make rows searchable
- Customize tables via CSS
- Trigger actions from cells
