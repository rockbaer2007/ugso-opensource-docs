# Débogage

Si votre configuration UIX ne produit pas l’effet attendu, les rubriques suivantes vous aideront à rechercher la cause.

- [Débogage des cartes](./cards.md)
- [Débogage des modèles](./templates.md)
- [Vider le cache](./cache.md)

Les causes fréquentes sont le cache du navigateur, des ressources de l’interface non rechargées, des sélecteurs incorrects ou des éléments Home Assistant affichés avec retard.

Consultez aussi les [outils d'inspection du DOM](../concepts/dom.md#dom-inspection-helpers) pour `uix_tree()`, `uix_style_path()` / `uix_path()`, `uix_forge_path()`, `uix_broker_path()` et `uix_broker_absolute_path()`.
