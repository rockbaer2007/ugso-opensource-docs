# Systèmes de test

- **système de test PC (64) – 192.168.178.193 :** nouvelle VM Proxmox (amd64) avec **8 Go de RAM et 4 vCPU** ; remplace .68 pour les prochains tests sur VM.
- **.68 – 192.168.178.68 :** ancienne VM Proxmox (amd64) avec **8 Go de RAM et 4 vCPU**. Les comptes rendus concernant .68 sont conservés comme historique.
- **système de test ARM (Pi 5) – 192.168.178.177 :** **Raspberry Pi 5 (ARM64) avec 8 Go de RAM et 4 cœurs CPU**.

Cette affectation des systèmes a été confirmée par l’utilisateur. Les résultats obtenus sur .68 ne constituent pas automatiquement une validation du système de test PC (64). Chaque compte rendu précise l’hôte, la version du logiciel et le périmètre du test.
