## Objectif pour la documentation des cartes {#ziel-fur-card-dokus}

La documentation d'une carte devrait inclure au minimum :

- L'installation via HACS et manuellement
- Un guide de démarrage rapide
- Une référence complète de la configuration
- Des exemples de cas d'utilisation typiques dans Home Assistant
- Des informations sur la version, la source originale et la licence
- Une mention claire indiquant qu'il s'agit d'une documentation non officielle, s'il s'agit d'un projet externe
