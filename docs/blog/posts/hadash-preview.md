# HADash v0.9.4 Preview

**2. August 2026 · HADash**

Mit der Version **v0.9.4-preview** wurde die Benutzeroberfläche von HADash vereinfacht.

## Was wurde geändert?

Das bisherige Theme-System wurde vollständig entfernt. HADash verwendet jetzt wieder die Standardfarben und Steuerelemente von Windows.

Dadurch wird die Oberfläche:

- übersichtlicher
- besser lesbar
- weniger fehleranfällig
- konsistenter mit anderen Windows-Anwendungen

## HADash

HADash ist ein portables Windows-Programm zum Einlesen, Sichern und Exportieren von Home-Assistant-Dashboards.

Das Programm kann unter anderem:

- JSON-Daten aus unverschlüsselten Home-Assistant-Backups einlesen
- Inhalte aus dem `.storage`-Ordner verarbeiten
- komplette Dashboards als YAML speichern
- einzelne Ansichten auswählen und exportieren
- Ansichten als TXT, YAML oder vollständiges Dashboard sichern
