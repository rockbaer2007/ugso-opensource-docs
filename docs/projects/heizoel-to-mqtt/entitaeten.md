# Entitäten

Die Entitäten werden per MQTT Discovery erstellt.

Für jede aktivierte Quelle und jede konfigurierte Liter-Menge entstehen:

- Preis pro 100 Liter
- Gesamtpreis
- Händler
- Lieferdauer
- Anzahl Angebote

Zusätzlich gibt es:

- Heizöl Verbindung
- Heizöl letzte Aktualisierung

Die Detailattribute enthalten Quelle, Menge, PLZ, Händler, Lieferdatum, Bewertung und Angebotsanzahl.
