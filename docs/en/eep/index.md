# <img class="eep-brand-logo" src="/images/eep/logo-eep.png" width="106" height="48" alt=""> EEP {#eep}

![EEP eisenbahn.exe professional 18 – railway construction and control simulation](/images/eep/eep18-banner.png)

![EEP 18 layout with a station, an ICE train and a freight train](/images/eep/eep18-layout.png)

> Immerse yourself in a realistic world of railway construction and operation with eisenbahn.exe professional – EEP 18. On your PC or laptop, design detailed landscapes with mountains, valleys and individual buildings. Create a sophisticated transport network and populate it with realistic rail and road vehicles controlled by a complex signalling system. Air and shipping traffic can also be integrated. The extensive selection of faithfully reproduced trains – from steam and diesel to electric locomotives and a wide variety of wagons – provides the foundation for authentic scenarios. EEP offers not only outstanding fidelity but also remarkable depth, with endless possibilities for designing layouts and experiencing complex scenarios.

## UGSo Software tools

Independent UGSo Software tools for editing EEP model descriptions and installation files.

## <img class="package-icon" src="/images/packages/eep-ini-edit-translate-2026.ico" width="32" height="32" alt="" aria-hidden="true"> INI Edit Translate 2026

The complete 2.1.37 release also includes Info_trans with the original database,
Firebird runtime and reviewed DE/EN/FR dictionary containing 2,428 entries.

Windows editor for EEP model INI files and `Installation.eep`, with MyMemory (translated.net) and optional ChatGPT/OpenAI translation. Since 2.1.55, the external CSV dictionary takes precedence. Edit model names, descriptions, movement axes and signal
functions in multiple languages.

- [Download Windows ZIP v2.1.55](https://github.com/rockbaer2007/ini-edit-translate-2026/releases/download/v2.1.55/INI-Edit-Translate-2026-v2.1.55-windows.zip)
- [GitHub release v2.1.55](https://github.com/rockbaer2007/ini-edit-translate-2026/releases/tag/v2.1.55)
- Archive: [Windows ZIP v2.1.38](https://github.com/rockbaer2007/ini-edit-translate-2026/releases/download/v2.1.38/INI-Edit-Translate-2026-v2.1.38-windows.zip) · [Release v2.1.38](https://github.com/rockbaer2007/ini-edit-translate-2026/releases/tag/v2.1.38)
- <img class="package-icon" src="/images/packages/eep-ini-edit-translate-2026.ico" width="32" height="32" alt="" aria-hidden="true"> [Features and usage](./ini-edit-translate-2026/)
- [Public GitHub repository](https://github.com/rockbaer2007/ini-edit-translate-2026)

The interface is available in German, English and French. Model texts support English,
German, French and Polish. GitHub updates are checked manually and installed after confirmation.
