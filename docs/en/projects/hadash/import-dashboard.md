# Import Dashboard

## Save the RAW Configuration from Home Assistant

1. Open the dashboard in edit mode.
2. Click the three dots in the top right.
3. Select **RAW configuration editor**.
4. Click into the code.
5. Press `CTRL + A`.
6. Press `CTRL + C`.
7. Paste the code into a text editor.
8. Save it as `Name.dash` or `Name.yaml`.

The file can then be opened in HADash.
