# Benutzerdefinierte Blockpakete

Für **UGSo Blocks for HA ab 0.1.18**. Hier stehen Beschreibung, kopierbarer Code und Downloads. Installation über [Block-/Template-Editor](../custom-blocks): JSON einfügen oder ZIP einlesen, prüfen und übernehmen.

| Paket | Inhalt | Code und Download |
| --- | --- | --- |
| Sensor und Licht · 1.0.0 | Sensorwert als Zahl, Grenzbedingung und Licht mit Helligkeit; rockbaer2007 · Apache-2.0 | [Paket öffnen](./sensor-light) |

Die separate Katalogseite ist unter [Visual Studio → Blockpakete](https://visualstudio.ugso-software.de/blocks) vorgesehen. Ihre Bereitstellung erfolgt über das Katalog-Deployment. Neue Pakete werden vor Veröffentlichung manuell geprüft; kein automatischer Upload aus dem Editor.
