# ioBroker-Veröffentlichungsassistent

Interaktive TypeScript-CLI für npm, GitHub und den ioBroker-Adapterkatalog.

Mit dem Menü kannst du Paketversion und Herkunftsnachweis prüfen, einen Trusted Publisher einrichten und einen Release über einen vorhandenen GitHub-Workflow starten. Für bestehende Katalog-PRs lässt sich eine erneute Prüfung auslösen.

Voraussetzungen sind Node.js ab Version 24, npm, Git und eine angemeldete GitHub CLI. Entpacke das ZIP und starte im entpackten Ordner `npm start -- menu`.
