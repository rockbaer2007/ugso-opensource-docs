# EEP

Independent UGSo Software tools for editing EEP model descriptions and installation files.

## INI Edit Translate 2026

The complete 2.1.37 release also includes Info_trans with the original database,
Firebird runtime and reviewed DE/EN/FR dictionary containing 2,428 entries.

Windows editor for EEP model INI files and `Installation.eep`, with ChatGPT translation
through the OpenAI API. Edit model names, descriptions, movement axes and signal
functions in multiple languages.

- [Download Windows ZIP v2.1.38](https://github.com/rockbaer2007/ini-edit-translate-2026/releases/download/v2.1.38/INI-Edit-Translate-2026-v2.1.38-windows.zip)
- [GitHub release](https://github.com/rockbaer2007/ini-edit-translate-2026/releases/tag/v2.1.38)
- [Features and usage](./ini-edit-translate-2026/)
- [Public GitHub repository](https://github.com/rockbaer2007/ini-edit-translate-2026)

The interface is available in German, English and French. Model texts support English,
German, French and Polish. GitHub updates are checked manually and installed after confirmation.

## Projektduplicator 2026

Duplicate and edit EEP model projects, with a DE/EN/FR/NL interface, Google web
translation, ZIP snapshots and manual GitHub updates.

- [Download and usage](./projektduplicator-2026/)
- [GitHub release 4.6.6.59](https://github.com/rockbaer2007/projektduplicator-2026/releases/tag/v4.6.6.59)
