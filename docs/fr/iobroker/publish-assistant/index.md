# Assistant de publication ioBroker

CLI TypeScript interactive pour npm, GitHub et le catalogue des adaptateurs ioBroker.

Le menu permet de vérifier la version et la provenance du paquet, de configurer un éditeur de confiance et de lancer une publication via un workflow GitHub existant. Vous pouvez également relancer la vérification d’une demande d’ajout au catalogue.

Node.js 24 ou ultérieur, npm, Git et une session GitHub CLI authentifiée sont nécessaires. Décompressez le ZIP et lancez `npm start -- menu` dans le dossier extrait.
