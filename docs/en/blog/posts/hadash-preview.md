# HADash v0.9.4 Preview

**August 2, 2026 · HADash**

With version **v0.9.4-preview**, the HADash user interface was simplified.

## What Changed?

The previous theme system was removed completely. HADash now uses the default
Windows colors and controls again.

This makes the interface:

- clearer
- easier to read
- less error-prone
- more consistent with other Windows applications

## HADash

HADash is a portable Windows program for reading, backing up and exporting Home
Assistant dashboards.

The program can:

- read JSON data from unencrypted Home Assistant backups
- process content from the `.storage` folder
- save complete dashboards as YAML
- select and export individual views
- save views as TXT, YAML or complete dashboards
