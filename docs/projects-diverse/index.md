# Diverse Projekte

Diese Seite sammelt weitere UGSo-Open-Source-Projekte, die nicht direkt zu den C#-Werkzeugen oder MQTT-Apps gehören.

## Ultimate Timer

**Ultimate Timer**

Ein Home-Assistant-Automations-Blueprint für wiederverwendbare Timer mit stabiler STOP-Logik, dauerhaftem DONE-Status, Multi-Instance-Unterstützung und optionalem MQTT-Betrieb.

- [Ultimate-Timer-Dokumentation öffnen](/projects/ultimate-timer/)
- [Blueprint auf GitHub öffnen](https://github.com/rockbaer2007/ha-ultimate-timer-blueprint)

## Home Assistant Blueprints

**Home Assistant Blueprints**

Eine kleine Sammlung eigener Home-Assistant-Blueprints fuer Verknuepfungen, Zielgruppen und Not-Aus-Funktionen. Enthalten sind Blueprints fuer eine Quelle mit bis zu sechs Zielen, eine Quelle mit frei waehlbarer Zielgruppe sowie eine Not-Aus-Automation, die beim Wechsel von `on` nach `off` ausgewaehlte Ziele ausschaltet.

- [Blueprints auf GitHub öffnen](https://github.com/rockbaer2007/homeassistant-blueprints)
