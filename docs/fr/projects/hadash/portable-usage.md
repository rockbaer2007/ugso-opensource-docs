# Utilisation en mode portable {#portable-nutzung}

HADash est conçu comme une application portable pour Windows.

## Avantages {#vorteile}

- Aucune installation classique
- Aucune inscription dans le registre
- Aucun stockage dans le dossier AppData
- Configuration conservée dans le dossier du programme
- Facilement copiable sur une clé USB ou un autre ordinateur

Les paramètres utilisateur se trouvent ici :

```text
config/user.config
```
