## Pourquoi HADash a été créé {#warum-hadash-entstanden-ist}

HADash est né de la volonté de pouvoir sauvegarder séparément des vues individuelles de tableaux de bord Home Assistant.

De plus, l'objectif était de permettre l'extraction de tableaux de bord complets à partir d'anciennes sauvegardes Home Assistant non chiffrées, ou depuis des fichiers JSON situés dans le dossier `.storage`, afin de les enregistrer à nouveau au format YAML.

::: warning Aperçu
HADash est encore en cours de développement. Vos retours, signalements de bugs et suggestions d'amélioration sont les bienvenus.
:::
