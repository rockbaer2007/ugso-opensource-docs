# Dashboard einlesen

## RAW-Konfiguration aus Home Assistant sichern

1. Dashboard im Bearbeitungsmodus öffnen.
2. Oben rechts auf die drei Punkte klicken.
3. **RAW-Konfigurationseditor** auswählen.
4. In den Code klicken.
5. `STRG + A` drücken.
6. `STRG + C` drücken.
7. Den Code in einen Texteditor einfügen.
8. Als `Name.dash` oder `Name.yaml` speichern.

Danach kann die Datei in HADash geöffnet werden.
