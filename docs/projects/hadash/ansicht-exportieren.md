# Ansicht exportieren

Nach dem Einlesen listet HADash die vorhandenen Dashboard-Ansichten auf.

## Exportmöglichkeiten

Eine ausgewählte Ansicht kann gespeichert werden als:

- `.txt`
- `.yaml`
- vollständiges neues Dashboard als `.dash`
- vollständiges neues Dashboard als `.yaml`

## Neues Dashboard aus einer Ansicht

1. Ansicht auswählen.
2. **Als Dashboard speichern** verwenden.
3. Neuen Namen vergeben.
4. Dateiformat auswählen.
5. Datei speichern.
