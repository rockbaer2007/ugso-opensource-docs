# Documentation HACS {#hacs-dokus}

Cet espace sert de zone de regroupement pour les projets HACS qui ne peuvent être clairement classés dans `HA Cards`, `HA Integrationen`, `HA Blueprints`, `HA Tools` ou `HA Apps und Add-ons`.

## Entrées actuelles {#geplant}

| Projet | État | Remarque |
| --- | --- | --- |
| Aucune entrée pour l'instant | ouvert | Les nouveaux documents HACS ne sont placés ici que s'il n'existe pas de catégorie plus appropriée. |

## Exigences {#anforderungen}

Pour chaque documentation HACS externe, les éléments suivants doivent être visibles :

- Nom du projet
- Dépôt d'origine
- Documentation originale
- État ou version de la traduction
- Licence et attribution
- Mention indiquant que la documentation originale fait foi
- État : à jour, à vérifier ou obsolète
