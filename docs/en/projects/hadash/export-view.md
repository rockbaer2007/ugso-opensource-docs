# Export View

After reading a dashboard, HADash lists the available dashboard views.

## Export Options

A selected view can be saved as:

- `.txt`
- `.yaml`
- a complete new dashboard as `.dash`
- a complete new dashboard as `.yaml`

## New Dashboard from One View

1. Select a view.
2. Use **Save as dashboard**.
3. Enter a new name.
4. Select the file format.
5. Save the file.
