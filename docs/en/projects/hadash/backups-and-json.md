# Backups and JSON

HADash can process dashboard data from unencrypted Home Assistant backups and
JSON content from the `.storage` folder.

## Typical Workflow

1. Extract the backup or copy the required file from `.storage`.
2. Open the JSON or YAML file in HADash.
3. Review the detected views.
4. Export the complete dashboard or individual views.

::: warning
Keep original backups unchanged and always work with a copy.
:::
