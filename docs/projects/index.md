## <img class="package-icon" src="/images/packages/sammlung-ha-automation-exporter.ico" width="32" height="32" alt="" aria-hidden="true"> Home Assistant Automation Exporter

Der Home Assistant Automation Exporter ist eine portable Windows-Anwendung zum Aufteilen einer `automations.yaml` in einzelne YAML-Dateien.
