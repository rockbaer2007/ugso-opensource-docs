# HADash v0.9.4 – Version préliminaire {#hadash-v0-9-4-preview}

**2 août 2026 · HADash**

Avec la version **v0.9.4-preview**, l'interface utilisateur de HADash a été simplifiée.

## Qu'est-ce qui a changé ? {#was-wurde-geandert}

L'ancien système de thèmes a été entièrement supprimé. HADash utilise désormais les couleurs et les contrôles standard de Windows.

Par conséquent, l'interface est désormais :

- moins encombrée
- plus facile à lire
- moins sujette aux erreurs
- plus cohérente avec les autres applications Windows

## HADash {#hadash}

HADash est une application Windows portable permettant d'importer, de sauvegarder et d'exporter des tableaux de bord Home Assistant.

Le programme permet, entre autres, de :

- Lire des données JSON à partir de sauvegardes Home Assistant non chiffrées
- Traiter le contenu du dossier `.storage`
- Enregistrer des tableaux de bord complets au format YAML
- Sélectionner et exporter des vues individuelles
- Enregistrer des vues au format TXT, YAML ou sous forme de tableau de bord complet
