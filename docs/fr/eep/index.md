# EEP

Outils indépendants d’UGSo Software pour modifier les descriptions de modèles EEP et
leurs fichiers d’installation.

## INI Edit Translate 2026

Éditeur Windows de fichiers INI de modèles EEP et d’`Installation.eep`, avec traduction
ChatGPT via l’API OpenAI. Modifier les noms, descriptions, axes de mouvement et
fonctions des signaux dans plusieurs langues.

- [Fonctions et utilisation](./ini-edit-translate-2026/)
- [Dépôt GitHub public](https://github.com/rockbaer2007/ini-edit-translate-2026)

L’interface est disponible en allemand, anglais et français. Les textes de modèles
prennent en charge l’anglais, l’allemand, le français et le polonais. La mise à jour
est actuellement désactivée.

EEP appartient à son titulaire respectif. Les outils UGSo présentés ici sont des développements indépendants.
