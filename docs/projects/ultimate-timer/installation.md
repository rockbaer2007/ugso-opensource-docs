# Installation

## Direkt in Home Assistant importieren

[![Blueprint in Home Assistant öffnen](https://my.home-assistant.io/badges/blueprint_import.svg)](https://my.home-assistant.io/redirect/blueprint_import/?blueprint_url=https://raw.githubusercontent.com/rockbaer2007/ha-ultimate-timer-blueprint/main/blueprints/automation/ultimate_timer_v3_2_4.yaml)

## Manuelle Installation

Lade diese Datei herunter:

```text
blueprints/automation/ultimate_timer_v3_2_4.yaml
```

Kopiere sie in dein Home-Assistant-Verzeichnis:

```text
config/blueprints/automation/
```

Danach in Home Assistant:

```text
Einstellungen
→ Automationen & Szenen
→ Blueprints
→ Blueprints neu laden
```
