# Outils HA {#ha-tools}

Cette section rassemble des outils externes liés à Home Assistant, aux tableaux de bord et au développement.

## Projets existants {#vorhandene-projekte}

| Projet | Description |
| --- | --- |
| [HADash](/fr/projects/hadash/) | Outil pour importer, modifier et exporter des tableaux de bord Home Assistant. |
| [Home Assistant Automation Exporter](/fr/collection/ha-automation-exporter/) | Outil Windows permettant d'exporter des automatisations individuelles depuis un fichier `automations.yaml` vers des fichiers YAML distincts. |

## Outils de développement internes {#interne-entwicklungswerkzeuge}

Certains dépôts sont utiles à notre développement, mais ne figurent pas dans la documentation publique de la collection :

| Outil | Utilité |
| --- | --- |
| custom-card-helpers | Bibliothèque auxiliaire et référence pour la création de cartes Lovelace/HACS personnalisées. |
| custom-card-devcontainer | Environnement de développement conteneurisé (devcontainer) pour tester des cartes personnalisées Home Assistant avec HACS et Node.js. |
