## Publier du code {#code-veroffentlichen}

VitePress détecte automatiquement le langage d'un bloc de code grâce à l'indication située après les trois backticks :

````md
```yaml
alias: Beispiel
triggers: []
actions: []
```
````

Sont pris en charge, entre autres :

- `yaml`
- `javascript` ou `js`
- `typescript` ou `ts`
- `json`
- `html`
- `css`
- `csharp`
- `powershell`
- `bash`
- `xml`
- `sql`

Chaque bloc de code est automatiquement doté d'un **bouton « Copier »**.
