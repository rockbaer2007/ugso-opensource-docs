## Vérification des modifications {#anderungsprufung}

L'action GitHub `Check Calendar Card Pro docs upstream` vérifie quotidiennement si des fichiers pertinents ont été modifiés dans le dépôt original. Elle peut également être déclenchée manuellement.

Éléments surveillés :

- `README.md`
- `docs/**/*.md`
- `package.json`
- `hacs.json`
- `LICENSE`
- `NOTICE`

Si des fichiers pertinents sont modifiés, l'action crée un « issue » (ticket) contenant un lien vers la comparaison et la liste des fichiers concernés.
