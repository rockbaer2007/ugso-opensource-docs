# Backups und JSON

HADash kann Dashboarddaten aus unverschlüsselten Home-Assistant-Backups sowie JSON-Inhalte aus dem `.storage`-Ordner verarbeiten.

## Typischer Ablauf

1. Backup entpacken oder die benötigte Datei aus `.storage` kopieren.
2. Die JSON- oder YAML-Datei in HADash öffnen.
3. Erkannte Ansichten prüfen.
4. Komplettes Dashboard oder einzelne Ansichten exportieren.

::: warning
Original-Backups unverändert aufbewahren und immer mit einer Kopie arbeiten.
:::
