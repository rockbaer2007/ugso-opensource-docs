# UIX Forge Sparks

Sparks erweitern ein von UIX Forge erzeugtes Element um einzelne, gekapselte Verhaltensweisen. Sie werden in `forge.sparks` als Liste definiert. Entities und Configuration unterstützen ab 9.2.0-beta.3 auch [Forge-Strategien](../forge#strategies).

## Verfügbare Sparks

- [Entities](./entities) – auto-entities-Filter für Listen, Abfragen und Templates, ab 9.2.0-beta.3.
- [Configuration](./config) – Konfigurationen und Strategieausgaben ändern, ab 9.2.0-beta.3.
- [Home Summary](./home-summary) – native Home-Zusammenfassungen filtern, ab 9.2.0-beta.3.
